# METADATA FIELDS REFERENCE

Every scripture edition `metadata.json` requires:
* `title`: Full title string
* `religion`: Registered religion
* `collection`: Registered collection
* `language`: Language name
* `script`: Script code (ISO 15924 / IAST / Deva)
* `license`: Public Domain or open CC license
* `source`: Provenance source
* `retrievalDate`: YYYY-MM-DD
